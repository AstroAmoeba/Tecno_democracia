
En el presente repositorio se presentan los contenidos pertinentes a la realización de la segunda parte de mi servicio social. A continuación una descripción de cada carpeta y sus contenidos.

# Contenidos


### 📁Artículo

Contiene archivos relacionados a la elaboración de un artículo.

### 📁Fuentes

Contiene un archivo "Tabla de fuentes" con la lista de fuentes empleadas y/o consultadas para la elaboración del Zine.

### 📁Imágenes

Contiene imágenes empleadas en las notas y/o en otras instancias. 

### 📁Notas

Contiene una serie de notas organizadas temáticamente por carpetas y sub carpetas. Las notas son principalmente una referencia para la elaboración del texto del Zine y posiblemente del artículo. 

### 📁Zine

Contiene lo pertinente a la elaboración del zine, como un boceto del texto propuesto, ideas y lista de pendientes. 

### 📄 Plan de trabajo 

Archivo pertinente a un plan de trabajo para la elaboración del zine. 

### 🖍️Mapa temático

Archivo .canvas con un par de diagramas.
